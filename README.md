# Pacman Game 🟡

A classic Pacman-style arcade game developed using Java and Java Swing.

## Features

- Player movement using keyboard arrows
- Multiple ghost enemies with random movement
- Collision detection system
- Score tracking system
- Lives system
- Game over screen
- Food collection mechanics
- Automatic map reload after winning

---

# Technologies Used

- Java
- Java Swing
- Java AWT
- Object-Oriented Programming (OOP)
